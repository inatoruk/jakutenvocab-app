# AI応答速度の検証（2026-10-29）

モデルは `gemini-3.5-flash-lite` のまま。新しい有料サービスや定期的なAI呼び出しは追加していない。

## 変更

- Vercel Functionsの実行地域を `iad1` から `hnd1` に変更。
- 意味・例文をNDJSONで逐次表示。JSON APIとの互換性は維持。
- タブ内メモリに意味・文脈付き言い換え判定を30分、合計最大200件保持。例文は使い回さない。
- グループ提案で独立した2つのDB問い合わせを並列実行。
- 入力本文やAPIキーを含めずに `ai-timing` を記録。JSON応答では `Server-Timing` も提供。

## 実測

同じ調査環境から公開サイトへ直列リクエスト。少数回の計測であり、負荷・語句・プロンプトは完全に同一ではない。ブラウザの描画時間は含まない。

変更前:

| 対象 | 回数 | 完了まで |
| --- | ---: | ---: |
| 意味 | 3 | 0.819–1.278秒 |
| 例文 | 4 | 0.795–1.074秒 |
| 言い換え判定 | 3 | 0.785–1.051秒 |
| 同じ生成コードからGeminiへ直接 | 4 | 0.606–0.837秒 |

変更後（本番リージョン `hnd1` をレスポンスヘッダーで確認）:

| 対象 | 初回文字まで | 完了まで |
| --- | ---: | ---: |
| デプロイ後最初の意味生成 | 3.540秒 | 3.633秒 |
| 例文・中級 | 0.601秒 | 0.734秒 |
| 例文・上級① | 0.546秒 | 0.711秒 |
| 別単語の意味生成 | 1.036秒 | 1.131秒 |
| 例文・上級② | 0.883秒 | 1.092秒 |
| 言い換え判定 | — | 0.826秒 |
| 同一意味のタブ内再表示 | 1ms未満 | 1ms未満 |
| 同一文脈・同一判定のタブ内再表示 | — | 1ms未満 |

「1ms未満」は通信と描画を除くクライアント関数の実測。画面描画が0msという意味ではない。

最初のリクエストのサーバーログ: ハンドラー開始からAI呼び出しまで4ms、AI呼び出しから最初の文字まで2,989ms、ハンドラー開始から完了まで3,095ms。ハンドラー開始前の起動や通信も別に存在する。したがって、この1回の遅延の多くはSDK呼び出し内の接続・Gemini応答待ちであり、サーバーの起動だけが原因とは判断できない。

## 限界と次の調査

- 初回の実生成を一律10倍速にしたわけではない。キャッシュが有効な繰り返しでは外部通信を省略できる。
- 最大10秒は今回再現できていない。時間帯、放置時間、ブラウザ側の計測との突き合わせが必要。
- グループ提案は本人の認証付きデータが必要なため実測していない。
- ストリーミングは全文完了前の表示を可能にするが、最初の文字以前の待ち時間は消せない。
- 定期pingや自動先読みで無料枠を消費する処理は追加していない。
